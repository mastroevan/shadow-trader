# Shadow Trader Demo Script

## 0:00-0:30 Problem

Retail investors and analysts are overloaded with quote movement, technical signals, and headlines. Most tools either show raw data or chat about it. Shadow Trader acts like a research agent: it gathers evidence, reasons over it, and creates a monitored action plan.

## 0:30-1:20 Live Analysis

Open Shadow Trader and click `NVDA`.

Show:

- Live quote card
- Percent move versus previous close
- Price change, volatility, news sentiment, and 20-day SMA signals
- Top headlines

## 1:20-2:10 Agent Thesis

Show the thesis card.

Point out:

- Directional view
- Confidence score
- Two bullish factors
- Two bearish factors
- Risk explanation
- Trace id for Arize

## 2:10-2:45 Action

Click `Add to Watchlist`.

Explain that the agent moved beyond answering: it created an entry trigger, invalidation rule, and watch conditions, then saved the setup for monitoring.

## 2:45-3:00 Partner Power

Open Arize and show the trace for the run. Explain that Arize makes the Gemini agent observable so the team can inspect run quality, latency, failures, and the evidence used in each thesis.
